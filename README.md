# СПОТЕР РІВНЕ 3D — браузерний симулятор транспорту

Окремий ігровий прототип версії 3.0 про транспорт Рівного. Доступні:

- синьо-білий тролейбус Škoda 14Tr, борт №107;
- жовта маршрутка №38 / 38А, номер ВК 1337 АА;
- 3D-сцена (WebGL) і резервний перспективний режим для пристроїв із заблокованим WebGL;
- водійська камера, вигляд позаду, збоку та салон;
- звуки двигуна / електромотора, дверей, штанг, сигналу й квитка;
- українські голосові оголошення зупинок (засобами браузера, якщо є голос українською);
- пасажири, квитки, зупинки, дощ, сніг, день і ніч;
- прямі й зворотні рейси з переліками зупинок, надісланими замовником.

**Важливо:** це авторський **ігровий прототип**, а не комерційний фотореалістичний симулятор. Вулиці та маршрути зображені у вигляді спрощеного 3D-міста, **не є точною географічною картою Рівного**. 3D-моделі відтворюють характерні форму й кольори транспорту, але це не сканування справжніх машин. Звуки синтезовані, а не записані в салоні реального тролейбуса. Гра одиночна, не multiplayer.

## Як запустити на комп'ютері

1. Розпакуйте весь ZIP-архів. **Не виймайте один `index.html` окремо**: поруч потрібні `main.js`, `style.css` і папка `assets`.
2. Двічі клацніть `index.html` і відкрийте в останній версії Google Chrome або Microsoft Edge.
3. Виберіть тролейбус чи маршрутку, напрямок, камеру, погоду і час доби.
4. Натисніть **«ПОЧАТИ РЕЙС»** або **«СІСТИ ЗА КЕРМО»**.
5. На початковій зупинці натисніть **O** (двері), **E** (посадка), ще раз **O** (зачинити двері) і тримайте **W** (газ).
6. Перед наступною зупинкою натисніть **S** (гальмо), після зупинки — **O**, **E**, **O**.
7. Коли проїдете всі зупинки, виберіть напрямок **«Назад»** і знову почніть рейс.

Звуки активуються після першої взаємодії з грою; доступність голосу `uk-UA` залежить від браузера та операційної системи.

## Керування

| Клавіша | Дія |
|---|---|
| W / ↑ | Газ |
| S / ↓ | Гальмування, утримання — задній хід |
| A / ← та D / → | Керування положенням у смузі |
| O | Відкрити / зачинити двері (тільки стоячи) |
| E | Посадка пасажирів біля зупинки |
| T | Видати квиток пасажиру |
| C | Перемкнути камеру |
| R | Підняти / опустити тролейбусні штанги |
| H | Сигнал |
| P | Пауза |

На телефоні є екранні кнопки під 3D-вікном.

## Як зробити онлайн-сайт на GitHub Pages

Ігрові файли вже підготовлено для **GitHub Pages**. Сервер, Node.js і платні послуги не потрібні.

1. Увійдіть на https://github.com/ .
2. Натисніть **+ → New repository** або перейдіть на https://github.com/new .
3. Назвіть репозиторій `spotter-rivne-3d`, установіть **Public** та натисніть **Create repository**.
4. У новому репозиторії натисніть **Add file → Upload files**. Перетягніть **вміст** розпакованої папки: `index.html`, `main.js`, `style.css`, `README.md`, `.nojekyll` і папку `assets` (усі 5 фото). Файли мають лежати в корені репозиторію, а не в зайвій папці.
5. Натисніть **Commit changes**.
6. Відкрийте **Settings → Pages**. У **Build and deployment** виберіть **Source: Deploy from a branch**; потім **main** і папку **/(root)**. Натисніть **Save**.
7. Дочекайтеся публікації. Далі в **Settings → Pages** з'явиться **Visit site**. Для прикладу, якщо власник репозиторію має нік `dacukpavlo` і назва — `spotter-rivne-3d`, адреса після успішного розгортання зазвичай має вигляд `https://dacukpavlo.github.io/spotter-rivne-3d/`. **Поки сторінка не опублікована, це лише приклад адреси, а не робоче посилання.**

Інструкції GitHub: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## Склад архіву

- `index.html` — інтерфейс, вибір маршруту, HUD, кнопки.
- `style.css` — оформлення та адаптивність для телефона.
- `main.js` — 3D-рушій WebGL, рух транспорту, шляхи, пасажири й звуки.
- `assets/` — фотографії від користувача (референси вигляду транспорту).
- `.nojekyll` — дозволяє GitHub Pages віддавати сайт як звичайні статичні файли.

**Право на фото:** перед публікацією у відкритому GitHub-репозиторії перевірте, чи маєте право публічно поширювати знімки. Якщо ні, замініть їх на власні або дозволені до використання.

## Подальші можливі доопрацювання

Реальна дорожня мережа на основі перевірених геоданих, детальніші моделі тролейбуса та маршрутки, власні записи звуків, повноцінний фізичний руль і гальма, світлофори/ПДР, озвучення професійним голосом, мережевий мультиплеєр.

## Публікація на GitHub Pages
Settings → Pages → Deploy from a branch → main / (root) → Save. Фотографії з ZIP потрібно покласти у папку `assets/` зі збереженням назв файлів.
